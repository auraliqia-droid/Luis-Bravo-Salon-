## ✨ Características

- **Diseño responsivo** — Experiencia optimizada en móvil, tablet y escritorio.
- **Galería de trabajos** — Portafolio visual con los mejores estilos y transformaciones del salón.
- **Catálogo de servicios** — Sección detallada con descripciones y precios de cada servicio.
- **Sistema de contacto directo** — Integración con WhatsApp, correo y teléfono en un solo clic.
- **Mapa interactivo** — Ubicación exacta del salón con Google Maps embebido.
- **Animaciones sutiles** — Transiciones suaves y micro-interacciones para una navegación premium.
- **SEO optimizado** — Estructura semántica y metadatos configurados para posicionamiento local.
- **Rendimiento** — Carga rápida con imágenes optimizadas y código minificado.

## 🚀 Instalación

### Prerrequisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- [Git](https://git-scm.com/) instalado
- Opcional: [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) para desarrollo local

### Pasos

```bash
# 1. Clonar el repositorio
git clone https://github.com/tu-usuario/luis-bravo-salon-lomas.git

# 2. Acceder al directorio del proyecto
cd luis-bravo-salon-lomas

# 3. Abrir en el navegador
open index.html
```

> También puedes utilizar la extensión **Live Server** de VS Code para levantar un servidor local con recarga automática.

---

## 💻 Uso

Una vez abierto el sitio en el navegador:

1. **Navega** por las secciones usando el menú principal o el scroll.
2. **Explora los servicios** disponibles con descripciones y precios.
3. **Consulta la galería** para ver el portafolio de trabajos recientes.
4. **Agenda tu cita** a través del botón de contacto directo vía WhatsApp.
5. **Encuentra el salón** con el mapa interactivo en la sección de ubicación.
